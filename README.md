## Getting Started

### Clone the repository

```bash
git clone https://github.com/yourFEdev/frontend-kidneyMate.git
```

### Navigate into the project

```bash
cd kidney-matte
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
